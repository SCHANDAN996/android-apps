# 07 — पंचांग का पूरा गणित

> हर सूत्र, हर तालिका, और वो कहाँ से आई। कोड बदलने से पहले यह पढ़ो।
> **कोई भी मान यहाँ बिना स्रोत के नहीं लिखा गया।**

**मुख्य संदर्भ:** Jean Meeus, *Astronomical Algorithms*, दूसरा संस्करण
**सत्यापन:** drikpanchang.com (वो भी दृक् गणित से चलता है) — पूरा लट्ठा `08_VERIFICATION.md` में

## 0. एक लाइन में पूरा विचार

> **पूरा पंचांग सिर्फ़ दो संख्याओं से निकलता है — सूर्य का देशांतर और चंद्र का देशांतर।**

बाक़ी सब उन्हीं दो का जोड़-घटाव है:

```
तिथि    ← चंद्र − सूर्य
नक्षत्र  ← चंद्र
योग     ← चंद्र + सूर्य
करण     ← चंद्र − सूर्य  (आधी तिथि)
मास     ← अमावस्या के वक़्त सूर्य किस राशि में था
```

इसलिए इंजन में **सिर्फ़ दो जगह असली खगोल-गणित है** — `sun.dart` और `moon.dart`। बाक़ी सब उनके ऊपर बैठा हिसाब है।

## 1. समय — JD, ΔT, और दो घड़ियाँ

`julian.dart`

पूरे इंजन में समय **दो** रूपों में चलता है। इन्हें कभी मत मिलाना:

| नाम | क्या है | किसके लिए |
|---|---|---|
| **JD (UT)** | घड़ी का समय | सूर्योदय, वार, दिखाने वाले सारे समय |
| **JDE (TT)** | गणित का समय | ग्रहों की स्थिति |

```
JDE = JD + ΔT / 86400
```

### जूलियन दिन
Meeus अध्याय 7:
```
अगर महीना ≤ 2:  साल −= 1,  महीना += 12
A = floor(साल / 100)
B = 2 − A + floor(A / 4)
JD = floor(365.25 × (साल + 4716)) + floor(30.6001 × (महीना + 1)) + दिन + B − 1524.5
```
**जाँच:** 1 जनवरी 2000, 12:00 = JD 2451545.0 (यह परिभाषा है) ✅

### ΔT
पृथ्वी का घूमना धीमा पड़ने से TT और UT में फ़र्क़ आता है। Espenak–Meeus (NASA) के बहुपद:

```
2005–2050:  t = साल − 2000
            ΔT = 62.92 + 0.32217·t + 0.005589·t²
```
(बाक़ी दौर के लिए भी अलग बहुपद कोड में हैं।)

आज लगभग **75 सेकंड**। पंचांग पर इसका असर छोटा है, पर तिथि की समाप्ति का समय बताते वक़्त वही 75 सेकंड दिखते हैं — इसलिए लगाया है।

> ⚠️ **खुला सवाल:** हमारे और Drik के बीच जो 30–60 सेकंड का पक्का फ़र्क़ बचा है, उसका सबसे संभावित कारण यही है। देखो `08_VERIFICATION.md` का "बचा हुआ फ़र्क़" वाला हिस्सा।

## 2. सूर्य का देशांतर

`sun.dart` · Meeus अध्याय 25 (कम-सटीकता वाला तरीक़ा, ~0.01°)

```
T  = (JDE − 2451545.0) / 36525

L₀ = 280.46646 + 36000.76983·T + 0.0003032·T²        (माध्य देशांतर)
M  = 357.52911 + 35999.05029·T − 0.0001537·T²        (माध्य विसंगति)

C  = (1.914602 − 0.004817·T − 0.000014·T²)·sin M
   + (0.019993 − 0.000101·T)·sin 2M
   + 0.000289·sin 3M                                  (केंद्र समीकरण)

Ω  = 125.04 − 1934.136·T

आभासी देशांतर λ☉ = L₀ + C − 0.00569 − 0.00478·sin Ω
```

आख़िरी दो पद: `−0.00569` प्रकाश की गति का सुधार (aberration), और `−0.00478·sin Ω` **नतांश** का छोटा रूप।
👉 यानी **सूर्य में नतांश पहले से शामिल है।** यह याद रखना ज़रूरी है (देखो अगला भाग)।

**सटीकता:** ~0.01° = 36 विकला। तिथि 12° चौड़ी है, तो यह समय में ~20 सेकंड बनता है।

## 3. चंद्र का देशांतर

`moon.dart` · Meeus अध्याय 47 · ELP-2000/82 का छोटा रूप, **60 पद**

```
T = (JDE − 2451545.0) / 36525

L′ = 218.3164477 + 481267.88123421·T − 0.0015786·T² + T³/538841 − T⁴/65194000
D  = 297.8501921 + 445267.1114034·T − 0.0018819·T² + T³/545868 − T⁴/113065000
M  = 357.5291092 + 35999.0502909·T − 0.0001536·T² + T³/24490000
M′ = 134.9633964 + 477198.8675055·T + 0.0087414·T² + T³/69699 − T⁴/14712000
F  = 93.2720950 + 483202.0175233·T − 0.0036539·T² − T³/3526000 + T⁴/863310000

A₁ = 119.75 + 131.849·T
A₂ = 53.09 + 479264.290·T
E  = 1 − 0.002516·T − 0.0000074·T²
```

तालिका 47.A के हर पद में: `D, M, M′, F` के गुणांक और `Σl` (10⁻⁶ डिग्री में)।

```
Σl = Σ [ गुणांक × E^|M का गुणांक| × sin(D·d + M·m + M′·m′ + F·f) ]
   + 3958·sin A₁ + 1962·sin(L′ − F) + 318·sin A₂

λ☾ = L′ + Σl/1000000 + Δψ
```

### ⚠️ `E` वाला सुधार
जिन पदों में `M` का गुणांक ±1 है, उन्हें `E` से गुणा करो; ±2 है तो `E²` से। **यह भूलना आसान है और चुपचाप ग़लती करता है।**

### ⚠️ नतांश — यह बग हो चुका है
Meeus का सूत्र *ज्यामितीय* देशांतर देता है। आभासी बनाने के लिए **Δψ जोड़ना पड़ता है।**

पहले यह छूट गया था — सूर्य में नतांश था, चंद्र में नहीं, और तिथि आधा मिनट खिसक रही थी। (→ D-013 के आसपास, `03_PROGRESS.md` 20 अगस्त)

**सटीकता:** ~10 विकला (0.003°)।
**पक्की जाँच:** Meeus उदाहरण 47.a — 12 अप्रैल 1992, 0h TD → किताब कहती है 133.167265°, हमारा **133.167233°**, फ़र्क़ **0.11 विकला** ✅

> यह जाँच `astronomy_test.dart` में स्थायी है। अगर तालिका में कोई अंक ग़लत टाइप होगा, **सिर्फ़ यही उसे पकड़ेगी।**

## 4. नतांश (Nutation)

`nutation.dart` · Meeus अध्याय 22, सरल रूप

```
Ω  = 125.04452 − 1934.136261·T
L  = 280.4665 + 36000.7698·T
L′ = 218.3165 + 481267.8813·T

Δψ = (−17.20·sin Ω − 1.32·sin 2L − 0.23·sin 2L′ + 0.21·sin 2Ω) / 3600   डिग्री
```

ज़्यादा से ज़्यादा 17 विकला। छोटा लगता है, पर चंद्रमा 13°/दिन चलता है — यानी लगभग **आधा मिनट**।

**नियम: सूर्य और चंद्र दोनों पर लगे, या दोनों पर न लगे।** एक पर लगाकर दूसरे पर भूलना ही असली ग़लती है।

## 5. अयनांश (लाहिड़ी)

`ayanamsa.dart`

```
T = (JDE − 2451545.0) / 36525
अयनांश = 23.8637885 + 1.3969713·T + 0.0003086·T²

निरयन देशांतर = सायन देशांतर − अयनांश
```

### यह मान कैसे तय हुआ
Drik से दो तारीख़ें मिलाईं, 9.4 साल के फ़ासले पर:

| तारीख़ | Drik | हमारा (पहले) | फ़र्क़ |
|---|---|---|---|
| 20-08-2026 | 24.235869° | 24.225000° | 0.010869° |
| 14-01-2036 | 24.367229° | 24.356361° | 0.010868° |

फ़र्क़ **दोनों जगह एक ही** — यानी चाल सही थी, बस शुरुआती मान 39 विकला नीचे था। स्थिरांक उतना बढ़ा दिया। अब मिलान **0.00001°** तक।

### सुधार की घुंडी
```dart
double ayanamsaCalibration = 0.0;   // डिग्री में; 1 विकला = 0.000278°
```
आगे कभी फ़र्क़ मिले तो **सिर्फ़ यही घुमाना।** बाक़ी कोड को हाथ मत लगाना।

### सबसे सच्ची जाँच — मकर संक्रांति
मकर संक्रांति = सूर्य का निरयन 270° पर पहुँचना। अयनांश ज़रा भी खिसके तो तारीख़ 13 या 16 जनवरी पर चली जाएगी।

**2024 से 2035 — हर साल 14 या 15 जनवरी** ✅ (जाँच स्थायी है)

## 6. पंचांग के पाँच अंग

`panchang.dart`

```
कोण                      = निरयन (जहाँ लिखा हो)

तिथि    = floor( ((चंद्र − सूर्य + 360) mod 360) / 12° )  + 1     → 1..30
नक्षत्र  = floor( चंद्र_निरयन / 13°20ʹ )                 + 1     → 1..27
योग     = floor( ((चंद्र_निरयन + सूर्य_निरयन) mod 360) / 13°20ʹ ) + 1  → 1..27
करण     = floor( ((चंद्र − सूर्य + 360) mod 360) / 6° )          → 0..59
वार     = सूर्योदय से अगले सूर्योदय तक
```

### ⚠️ सबसे बड़ी बात
**हिंदू दिन सूर्योदय से सूर्योदय तक होता है, रात 12 बजे से नहीं।**
"आज की तिथि" = *आज सूर्योदय के समय जो तिथि चल रही थी*।
यह एक बात ग़लत हुई तो पूरा पंचांग एक दिन खिसक जाएगा।

### तिथि नोट
- तिथि और करण **सायन** देशांतरों से भी वही आते हैं, क्योंकि अयनांश घटाने पर कट जाता है
- नक्षत्र और योग में **निरयन** ज़रूरी है
- नतांश तिथि/करण में कट जाता है, नक्षत्र में नहीं

### करण के नाम
एक चांद्र मास में 60 करण। पहला हमेशा **किंस्तुघ्न**, आख़िरी तीन **शकुनि–चतुष्पाद–नाग**, बीच के 56 में सात चर करण (बव, बालव, कौलव, तैतिल, गर, वणिज, विष्टि) आठ बार दोहराते हैं।

```
गिनती 0        → किंस्तुघ्न
गिनती 1–56     → चर[(गिनती − 1) mod 7]
गिनती 57,58,59 → शकुनि, चतुष्पाद, नाग
```

## 7. समाप्ति का समय — जड़-खोज

चारों अंगों के कोण **हमेशा आगे ही बढ़ते हैं**, कभी पीछे नहीं जाते। इसलिए सीधा द्विभाजन (bisection) काफ़ी है।

```
gap(jd) = norm180( कोण(jd) − लक्ष्य )

आगे की तरफ़: 0.02 दिन (≈29 मिनट) के क़दमों से चलो,
             जहाँ gap ऋणात्मक से धनात्मक हो वहाँ द्विभाजन
पीछे की तरफ़: वही, उल्टी दिशा में  (अंग की शुरुआत निकालने के लिए)

सटीकता: 1 सेकंड
```

`findCrossing()` और `findPreviousCrossing()` — `panchang.dart` में।

**चालें प्रति दिन (क़दम का आकार तय करने के लिए):**
| अंग | चाल | अवधि |
|---|---|---|
| तिथि | ~12.19° | 19–26 घंटे |
| नक्षत्र | ~13.18° | ~24 घंटे |
| योग | ~14.17° | ~22 घंटे |
| करण | ~12.19° (6° चौड़ा) | ~12 घंटे |

## 8. सूर्योदय और सूर्यास्त

`sunrise.dart`

Meeus की interpolation वाली विधि की जगह **सीधा जड़-खोज** — कम कोड, कम ग़लती की गुंजाइश।

```
क्षितिज की ऊँचाई h₀ = −0.8333°
                     ( −34ʹ वायुमंडलीय अपवर्तन  −16ʹ सूर्य का अर्धव्यास )

GMST(jd) = 280.46061837 + 360.98564736629·(jd − 2451545.0)
           + 0.000387933·T² − T³/38710000

ε   = माध्य तिरछाहट + 0.00256·cos(125.04 − 1934.136·T)
α   = atan2( cos ε · sin λ☉ , cos λ☉ )              दाहिना आरोहण
δ   = asin( sin ε · sin λ☉ )                        क्रांति
H   = GMST + देशांतर − α                             घंटा-कोण
ऊँचाई = asin( sin φ·sin δ + cos φ·cos δ·cos H )
```

फिर स्थानीय आधी रात से 10 मिनट के क़दमों से पूरा दिन छानो, जहाँ ऊँचाई `h₀` को पार करे वहाँ द्विभाजन (1 सेकंड तक)।

**जाँच:** दिल्ली, पटना, जयपुर, नागपुर, चेन्नई — पाँचों में Drik से **1–25 सेकंड** ✅
(चेन्नई 15 सितम्बर 2026: दोनों **05:58:00** — सेकंड तक)

**जो नहीं जोड़ा:** जगह की ऊँचाई (altitude) का सुधार। मैदानी इलाक़ों में असर 1–2 मिनट।

## 9. मास — अमांत, पूर्णिमांत, अधिक

```
अमावस्या ढूँढो जो इस क्षण से पहले पड़ी      (elongation = 0)
उस क्षण सूर्य की निरयन राशि = r             (0 = मेष)

अमांत मास = (r + 1) mod 12                  (0 = चैत्र)
```

**क्यों `+1`:** अमावस्या पर सूर्य मीन (r=11) में हो → चैत्र (0)।

### पूर्णिमांत
```
अगर पूर्णिमांत  और  कृष्ण पक्ष  और  अधिक मास नहीं:
      मास = (अमांत + 1) mod 12
वरना: मास = अमांत
```

पूर्णिमांत मास पूर्णिमा पर बदलता है, इसलिए कृष्ण पक्ष के दौरान नाम एक आगे का होता है।

### ⚠️ अधिक मास में `+1` नहीं लगता — यह बग हो चुका है
अधिक मास पूरा का पूरा एक **अतिरिक्त** महीना है, इसलिए उसमें दोनों पद्धतियाँ **एक ही नाम** लेती हैं।

Drik 1 जून 2026 (कृष्ण प्रतिपदा) पर दोनों जगह "Jyeshtha (Adhik)" लिखता है। हम "आषाढ़" दिखा रहे थे। (→ **D-015**)

### अधिक मास की पहचान
```
अगर इस अमावस्या और अगली अमावस्या पर सूर्य की राशि एक ही है
→ बीच में कोई संक्रांति नहीं हुई → अधिक (पुरुषोत्तम) मास
```

**2026 में अधिक ज्येष्ठ — 17 मई से 15 जून।** Drik से पक्का ("Purushottam Masa Day 16")।

दिखाते वक़्त हमेशा `masaFullName` इस्तेमाल करो — वो "अधिक ज्येष्ठ" लौटाता है।

## 10. संवत् और संवत्सर

```
चैत्र शुक्ल प्रतिपदा से नया साल (मार्च–अप्रैल में पड़ता है)

महीना ≥ 5      → शक = साल − 78
महीना ≤ 2      → शक = साल − 79
महीना 3 या 4   → फाल्गुन चल रहा हो तो साल−79, वरना साल−78

विक्रम = शक + 135
```

### संवत्सर — साठ साल का बृहस्पति चक्र
```
शक संवत्सर    = संवत्सर[ (शक + 11) mod 60 ]      ← दक्षिण का क्रम
विक्रम संवत्सर = संवत्सर[ (विक्रम + 9) mod 60 ]   ← उत्तर का क्रम
```

दोनों चक्र **13 साल आगे-पीछे** चलते हैं। **यह भूल नहीं — दो अलग परंपराएँ हैं**, इसलिए दोनों अलग-अलग दिखाने हैं।

**जाँच (Drik से, दो-दो तारीख़ें):**
शक 1948 → पराभव · शक 1949 → प्लवंग
विक्रम 2083 → सिद्धार्थी · विक्रम 2084 → रौद्र ✅

## 14.5 चंद्रोदय और चंद्रास्त

`moon.dart` (तालिका 47.B, Σr) + `moonrise.dart`

### चंद्र का अक्षांश (β)
तालिका 47.B, 60 पद। बनावट देशांतर जैसी ही, पर छह अलग जोड़ आख़िर में:

```
Σb += −2235·sin L′ + 382·sin A₃ + 175·sin(A₁ − F)
    +  175·sin(A₁ + F) + 127·sin(L′ − M′) − 115·sin(L′ + M′)

β = Σb / 1000000            → −5.2° से +5.2° के बीच
```

⚠️ **अक्षांश पर नतांश नहीं लगता** — वो सिर्फ़ देशांतर को खिसकाता है।

### दूरी और लंबन
```
Σr तालिका 47.A का दूसरा खंभा (cos वाले पद, sin नहीं)
Δ = 385000.56 + Σr/1000        किलोमीटर
π = asin(6378.14 / Δ)          क्षैतिज लंबन, ~0.95°
```

### भूमध्य निर्देशांक
सूर्य से फ़र्क़: चंद्र का β शून्य नहीं होता, इसलिए पूरा सूत्र लगता है।
```
α = atan2( sin λ·cos ε − tan β·sin ε , cos λ )
δ = asin( sin β·cos ε + cos β·sin ε·sin λ )
```

### क्षितिज की ऊँचाई — यहीं सूर्य से सबसे बड़ा फ़र्क़ है
```
सूर्य के लिए:   h₀ = −0.8333°        (अपवर्तन + अर्धव्यास)
चंद्र के लिए:   h₀ = 0.7275·π − 34ʹ  ≈ +0.1°
```

सूरज इतनी दूर है कि लंबन नगण्य। चंद्रमा पास है — **इसलिए वो क्षितिज से
ऊपर उगता है, नीचे नहीं।**

### ⚠️ हर दिन चंद्रोदय नहीं होता
चंद्रमा रोज़ ~50 मिनट देर से उगता है, इसलिए महीने में एक-दो दिन ऐसे आते
हैं जब उदय (या अस्त) उस तारीख़ में पड़ता ही नहीं। **`null` लौटना ग़लती
नहीं है** — छपे पंचांग में भी वहाँ जगह ख़ाली रहती है।

### अनसुलझा फ़र्क़ — Drik से ~5 मिनट
Drik के बताए क्षणों पर हमारी गणना में ऊँचाई ~**+0.97°** निकलती है, मानक
**+0.09°** कहता है। Drik की दहलीज़ लंबन के साथ बदलती नहीं, हमारी बदलती है।

**यह स्थिति की ग़लती नहीं** — घुंडी `moonHorizonAdjustment = 0.88` रखते ही
Drik से एक मिनट के भीतर मिलान हो जाता है (यह जाँच स्थायी है)। मानक ही
रखा गया (→ D-016)। छपे पंचांग से जाँचकर ही तय होगा।

## 14.6 व्यापिनी नियम — त्योहार की तारीख़ें

`festival.dart`

> **"सूर्योदय की तिथि" हर त्योहार का नियम नहीं है।** शास्त्र में हर
> त्योहार के लिए अलग है कि तिथि *किस काल में* चालू होनी चाहिए।

### पाँच काल
```
सूर्योदय   = सूर्योदय का क्षण
मध्याह्न   = दिन (सूर्योदय→सूर्यास्त) के 5 भाग, तीसरा
अपराह्न    = वही 5 भाग, चौथा
प्रदोष     = सूर्यास्त से 2 घंटे 24 मिनट (3 मुहूर्त)
निशीथ      = रात (सूर्यास्त→अगला सूर्योदय) के 15 मुहूर्त, आठवाँ
```

⚠️ **निशीथ की खिड़की आधी रात के *बाद* पड़ती है** — 20 तारीख़ का निशीथ असल
में 21 की सुबह ~00:30 पर होता है। दावेदार दिन ढूँढते वक़्त एक दिन **पीछे**
से शुरू करना पड़ता है, वरना कुछ सालों में त्योहार ग़ायब हो जाता है।

### किस त्योहार पर कौन सा
| नियम | त्योहार |
|---|---|
| सूर्योदय | घटस्थापना, ज़्यादातर व्रत, एकादशी |
| मध्याह्न | राम नवमी, गणेश चतुर्थी |
| अपराह्न | रक्षाबंधन, श्राद्ध |
| प्रदोष | दीपावली, होलिका दहन |
| निशीथ | महाशिवरात्रि, जन्माष्टमी |

### भद्रा वाला नियम
पूर्णिमा का पहला आधा हिस्सा **हमेशा** विष्टि करण (भद्रा) होता है —
क्योंकि करण = कोण/6°, और पूर्णिमा 168°–180° की होती है:
```
करण गिनती 28 → (28−1) mod 7 = 6 = विष्टि (भद्रा)
करण गिनती 29 → (29−1) mod 7 = 0 = बव
```

> **अगर भद्रा उस दिन के ज़रूरी काल को पूरा ढक ले, और अगले दिन के सूर्योदय
> पर तिथि अब भी चल रही हो — तो त्योहार अगले दिन खिसक जाता है।**

यही एक नियम दोनों को सही करता है:
- होलिका दहन 2026: 2 मार्च का प्रदोष भद्रा में डूबा → **3 मार्च**
- रक्षाबंधन 2026: 27 अगस्त का अपराह्न भद्रा में डूबा → **28 अगस्त**

### क्षय तिथि वाला नियम
कभी तिथि इतनी छोटी पड़ती है कि ज़रूरी काल को छूती ही नहीं। जैसे 2027 की
घटस्थापना — प्रतिपदा 30/9 08:06 से 1/10 05:35 तक, और दोनों दिन सूर्योदय
06:13 पर। किसी सूर्योदय को छुआ ही नहीं।

तब: **जिस हिंदू दिन (सूर्योदय→अगला सूर्योदय) में तिथि सबसे ज़्यादा देर
रहे, वही दिन।** नतीजा `missedKaal` की झंडी के साथ आता है।

### मास कैसे मिलाया जाता है
```
पूर्णिमांत + कृष्ण पक्ष  →  अमांत मास = (त्योहार का मास − 1) mod 12
वरना                     →  अमांत मास = त्योहार का मास

अधिक मास छोड़ दो — त्योहार अधिक मास में नहीं मनाए जाते
```

### जो जान-बूझकर नहीं किया
दो दिन दावेदार हों तो पूरा शास्त्रीय नियम नहीं लगाया — `ambiguous` की
झंडी लगती है। **ऐप को ऐसे में दोनों दिन दिखाने चाहिए**, चुपचाप एक चुनकर
यूज़र को धोखे में नहीं रखना।

## 14.7 चौघड़िया और होरा

`muhurta.dart`

दोनों एक ही जड़ से निकलते हैं — **वार के स्वामी ग्रह से।**

### होरा-क्रम (कल्दियन क्रम का उल्टा)
```
सूर्य → शुक्र → बुध → चंद्र → शनि → गुरु → मंगल → सूर्य …
  0       1       2      3      4      5      6
```

### वार का स्वामी — यही दोनों की शुरुआत तय करता है
```
रवि  सोम  मंगल  बुध  गुरु  शुक्र  शनि
 0    3    6     2    5     1     4        ← होरा-क्रम में जगह
```

### चौघड़िया के नाम = उन्हीं ग्रहों के गुण
```
उद्वेग(सूर्य)  चर(शुक्र)  लाभ(बुध)  अमृत(चंद्र)
काल(शनि)      शुभ(गुरु)  रोग(मंगल)

शुभ  = चर, लाभ, अमृत, शुभ
अशुभ = उद्वेग, काल, रोग
```

### गणना
```
दिन  = सूर्योदय→सूर्यास्त के 8 भाग    चौघड़िया
रात  = सूर्यास्त→अगला सूर्योदय के 8 भाग

दिन का n-वाँ  =  (वार का स्वामी + n) mod 7
रात का n-वाँ  =  (वार का स्वामी + 5 − 2n) mod 7
```

### ⚠️ रात का क्रम उल्टा चलता है
दिन में हर अगली चौघड़िया होरा-क्रम में **एक क़दम आगे** बढ़ती है, पर
**रात में दो क़दम पीछे**। याददाश्त से लिखने पर यहीं ग़लती हुई थी —
Drik से मिलाने पर ही पकड़ में आई।

### होरा
```
दिन  = सूर्योदय→सूर्यास्त के 12 भाग
रात  = सूर्यास्त→अगला सूर्योदय के 12 भाग

n-वाँ होरा = होरा-क्रम[(वार का स्वामी + n) mod 7]
```

**होरा एक घंटे का नहीं होता।** 20 अगस्त 2026 दिल्ली में दिन का होरा
65 मिनट का था, रात का 54 मिनट का।

### सबसे सुंदर बात
सूर्योदय से **24 होरा** गिनो तो अगले सूर्योदय पर अगले वार का स्वामी आ
जाता है। गुरुवार से शुरू करो: 24 क़दम बाद शुक्र — और अगला दिन शुक्रवार।
**वारों का क्रम इसी से बना है।** (यह जाँच `muhurta_test.dart` में स्थायी है।)
