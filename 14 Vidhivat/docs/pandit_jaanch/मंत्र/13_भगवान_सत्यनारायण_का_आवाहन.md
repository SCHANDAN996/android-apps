# मंत्र 13 — भगवान सत्यनारायण का आवाहन

**भरोसा:** मध्यम · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ॐ भूर्भुवः स्वः श्रीसत्यनारायणाय नमः।
श्रीसत्यनारायण! इहागच्छ, इह तिष्ठ।
आवाहयामि, स्थापयामि, ध्यायामि।
आसनं समर्पयामि।
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
om bhurbhuvah svah shri-satyanarayanaya namah |
shri-satyanarayana! ihagachchha, iha tishtha |
avahayami, sthapayami, dhyayami |
asanam samarpayami |
```

## अर्थ (अपना लिखा हुआ)

हे भगवान सत्यनारायण, यहाँ पधारिए और यहीं विराजिए। मैं आपका आवाहन करता हूँ, स्थापना करता हूँ, ध्यान करता हूँ — और बैठने के लिए आसन अर्पित करता हूँ।

## दूसरा चलन

आवाहन से पहले एक ध्यान-श्लोक भी बोला जाता है जो पद्धति से बदलता है — वो अभी नहीं लिखा गया। पंडित जी से पूछें कि उसे जोड़ना है या नहीं।

## स्रोत
