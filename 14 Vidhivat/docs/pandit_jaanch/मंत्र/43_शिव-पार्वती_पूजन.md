# मंत्र 43 — शिव-पार्वती पूजन

**भरोसा:** मध्यम · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ॐ उमायै नमः। ॐ पार्वत्यै नमः।
ॐ नमः शिवाय॥
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
om umayai namah | om parvatyai namah |
om namah shivaya ||
```

## अर्थ (अपना लिखा हुआ)

उमा (पार्वती) को नमस्कार, पार्वती को नमस्कार, और शिव को नमस्कार।

## दूसरा चलन

बहुत घरों में इनकी जगह लंबे स्तोत्र या तीज की कथा पढ़ी जाती है। रेत या मिट्टी से शिव-पार्वती की मूर्ति बनाकर पूजने की विधि क्षेत्र से बहुत बदलती है, इसलिए उसका अलग मंत्र नहीं दिया गया।

## स्रोत

हरितालिका तीज की पूजा-विधियों में शिव और पार्वती के यही नाम-मंत्र दिए जाते हैं (jeevanjali, bhaktvatsal)। यह पर्व शिव-पार्वती के मिलन का है, इसलिए दोनों का पूजन साथ होता है।

## यह पाठ कहाँ-कहाँ चलता है (1 जगह)

- हरितालिका तीज — *शिव-पार्वती पूजन*
