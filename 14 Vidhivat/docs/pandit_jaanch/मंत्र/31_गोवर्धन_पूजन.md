# मंत्र 31 — गोवर्धन पूजन

**भरोसा:** मध्यम · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ॐ गोवर्धनधराय नमः॥
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
om govardhana-dharaya namah ||
```

## अर्थ (अपना लिखा हुआ)

गोवर्धन पर्वत को धारण करने वाले (श्रीकृष्ण) को नमस्कार।

## दूसरा चलन

गोबर से गोवर्धन पर्वत की आकृति बनाकर उस पर फूल, अक्षत और दीप रखकर पूजा की जाती है, फिर परिक्रमा होती है।

## स्रोत

गोवर्धन पूजन का प्रचलित नाम-मंत्र। गोवर्धन पर्वत को उठाकर कृष्ण ने ब्रजवासियों को इंद्र के प्रकोप से बचाया था — यही इस पूजा की कथा है (thedivineindia, bhaktvatsal)।

## यह पाठ कहाँ-कहाँ चलता है (1 जगह)

- गोवर्धन पूजा / अन्नकूट — *गोवर्धन पूजन*
