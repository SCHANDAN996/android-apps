# मंत्र 4 — दीप प्रज्वलन

**भरोसा:** ऊँचा · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
भो दीप! देवरूपस्त्वं कर्मसाक्षी ह्यविघ्नकृत्।
यावत्कर्मसमाप्तिः स्यात् तावत्त्वं सुस्थिरो भव॥
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
bho dipa! devarupas tvam karmasakshi hy avighnakrit |
yavat karmasamaptih syat tavat tvam susthiro bhava ||
```

## अर्थ (अपना लिखा हुआ)

हे दीपक, तुम देवता के रूप हो, इस काम के साक्षी हो और विघ्न हटाने वाले हो — जब तक यह पूजा पूरी न हो जाए, तब तक स्थिर जलते रहो।

## दूसरा चलन

छपे पाठों में कहीं कर्म-साक्षी और कहीं कर्मसाक्षी लिखा मिलता है — अर्थ वही है।
