# मंत्र 8 — जल चढ़ाना

**भरोसा:** ऊँचा · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ॐ तुलस्यै नमः।
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
om tulasyai namah |
```

## अर्थ (अपना लिखा हुआ)

तुलसी का सरल नाम-मंत्र। जल चढ़ाते और दीपक दिखाते समय यही बोला जाता है।

## दूसरा चलन

कुछ घरों में "ॐ श्री तुलस्यै विद्महे" वाला लंबा मंत्र भी बोला जाता है।

## स्रोत

तुलसी का प्रचलित नाम-मंत्र। नाम-मंत्र हर पद्धति में एक जैसे मिलते हैं।

## यह पाठ कहाँ-कहाँ चलता है (1 जगह)

- तुलसी पूजा — *जल चढ़ाना*
