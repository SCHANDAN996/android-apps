# मंत्र 27 — उपचार अर्पण

**भरोसा:** ऊँचा · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ॐ सरस्वत्यै नमः।
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
om sarasvatyai namah |
```

## अर्थ (अपना लिखा हुआ)

सरस्वती जी का सरल नाम-मंत्र। हर उपचार अर्पित करते समय यही बोला जाता है।

## दूसरा चलन

कुछ घरों में "ॐ ऐं सरस्वत्यै नमः" बीज के साथ बोला जाता है।

## स्रोत

देवी का प्रचलित नाम-मंत्र। नाम-मंत्र हर पद्धति में एक जैसे मिलते हैं, इसलिए इनमें फ़र्क़ की गुंजाइश सबसे कम है।

## यह पाठ कहाँ-कहाँ चलता है (1 जगह)

- सरस्वती पूजा — *उपचार अर्पण*
