# मंत्र 37 — औज़ार, मशीन और वाहन पूजन

**भरोसा:** मध्यम · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ॐ विश्वकर्मणे नमः॥
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
om vishvakarmane namah ||
```

## अर्थ (अपना लिखा हुआ)

भगवान विश्वकर्मा को नमस्कार।

## दूसरा चलन

कुछ पद्धतियों में "श्री" जोड़कर "ॐ श्रीविश्वकर्मणे नमः" बोला जाता है — दोनों चलन हैं।

## स्रोत

विश्वकर्मा पूजा की छपी विधियों में एक जैसा मिलने वाला नाम-मंत्र (हवन में "ॐ विश्वकर्मणे नमः स्वाहा"; दरभंगा संस्कृत विश्वविद्यालय के डॉ. अखिलेश कुमार मिश्र की पद्धति में "ॐ श्रीविश्वकर्मणे नमः")। नाम-मंत्र हर पद्धति में लगभग एक जैसे मिलते हैं।

## यह पाठ कहाँ-कहाँ चलता है (1 जगह)

- विश्वकर्मा पूजा — *औज़ार, मशीन और वाहन पूजन*
