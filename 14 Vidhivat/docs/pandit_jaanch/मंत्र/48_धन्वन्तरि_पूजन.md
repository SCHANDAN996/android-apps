# मंत्र 48 — धन्वन्तरि पूजन

**भरोसा:** मध्यम · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ॐ धन्वन्तरये नमः॥
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
om dhanvantaraye namah ||
```

## अर्थ (अपना लिखा हुआ)

आरोग्य के देवता धन्वन्तरि को नमस्कार।

## दूसरा चलन

बहुत लोग "ॐ नमो भगवते वासुदेवाय धन्वन्तरये…" वाला लंबा मंत्र भी जपते हैं — वह वैद्य और आरोग्य के लिए है।

## स्रोत

धनतेरस पूजन की विधियों में धन्वन्तरि का नाम-मंत्र यही दिया जाता है (mnsgranth, webdunia)। धन्वन्तरि समुद्र-मंथन से इसी दिन प्रकट हुए माने जाते हैं, इसलिए इसे धन्वन्तरि जयंती भी कहते हैं।

## यह पाठ कहाँ-कहाँ चलता है (1 जगह)

- धनतेरस पूजा — *धन्वन्तरि पूजन*
