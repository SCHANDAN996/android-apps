# मंत्र 58 — नवग्रह और षोडश मातृका पूजन

**भरोसा:** ऊँचा · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
ब्रह्मा मुरारिस्त्रिपुरान्तकारी भानुः शशी भूमिसुतो बुधश्च।
गुरुश्च शुक्रः शनिराहुकेतवः सर्वे ग्रहाः शान्तिकरा भवन्तु॥
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
brahma muraris tripurantakari bhanuh shashi bhumisuto budhashcha |
gurushcha shukrah shanirahuketavah sarve grahah shantikara bhavantu ||
```

## अर्थ (अपना लिखा हुआ)

ब्रह्मा, मुरारि (विष्णु), त्रिपुरान्तकारी (शिव), सूर्य, चंद्र और अन्य सभी नवग्रह हमारे लिए शांति देने वाले हों। यह नवग्रहों से मंगल और शांति की प्रार्थना है।

## दूसरा चलन

यह नवग्रह पूजन के अंत की वैकल्पिक शांति-प्रार्थना है, नौ ग्रहों के अलग-अलग आवाहन/पूजन मंत्रों या षोडश मातृका के सोलह नामों का विकल्प नहीं। वे विस्तृत पाठ अभी ऐप में नहीं जोड़े गए हैं।

'कुर्वन्तु सर्वे मम सुप्रभातम्' वाली अंतिम पंक्ति का रूप प्रातः-स्मरण में मिलता है; यहाँ पूजा-संग्रह में दिए 'सर्वे ग्रहाः शान्तिकरा भवन्तु' वाले रूप को रखा गया है।

## स्रोत

पूजा संग्रह, नवग्रह पूजन, पृ. १०८: नमस्कार में 'सर्वे ग्रहाः शान्तिकरा भवन्तु' वाला पाठ।
