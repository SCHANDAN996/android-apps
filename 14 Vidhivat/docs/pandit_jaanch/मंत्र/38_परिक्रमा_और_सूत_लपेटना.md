# मंत्र 38 — परिक्रमा और सूत लपेटना

**भरोसा:** मध्यम · **हालत:** ⬜ पंडित जी से पास नहीं

## पाठ

```
यथा शाखाप्रशाखाभिर्वृद्धोऽसि त्वं महीतले।
तथा ममापि सौभाग्यं वृद्धिं कुर्याद् जनार्दन॥
```

## रोमन (सिर्फ़ पढ़ने की सहायता, उच्चारण का नियम नहीं)

```
yatha shakha-prashakhabhir vriddho'si tvam mahitale |
tatha mamapi saubhagyam vriddhim kuryad janardana ||
```

## अर्थ (अपना लिखा हुआ)

हे वट वृक्ष, जैसे तुम अपनी शाखाओं-प्रशाखाओं से इस धरती पर बढ़ते जाते हो, वैसे ही मेरा सौभाग्य भी बढ़ता रहे।

## दूसरा चलन

परिक्रमा करते हुए हर चक्कर पर कच्चा सूत लपेटा जाता है — आम तौर पर सात या एक सौ आठ बार। संख्या क्षेत्र और परिवार से बदलती है।

## स्रोत

वट वृक्ष की परिक्रमा करते समय बोला जाने वाला प्रचलित मंत्र (timesnowhindi, bhaktvatsal)। वट सावित्री की पूजा-विधियों में यही रूप मिला।

## यह पाठ कहाँ-कहाँ चलता है (1 जगह)

- वट सावित्री व्रत — *परिक्रमा और सूत लपेटना*
