## चरण A — पंचांग इंजन (सितम्बर 2026, 4 हफ़्ते)

पूरा पंचांग सिर्फ़ दो चीज़ों से निकलता है: **सूर्य का देशांतर और चंद्र का देशांतर।**

```
निरयन देशांतर = सायन देशांतर − लाहिरी अयनांश

तिथि   = floor( ((चंद्र − सूर्य + 360) mod 360) / 12 ) + 1      → 1..30
नक्षत्र = floor( चंद्र / 13.333333 ) + 1                         → 1..27
योग    = floor( ((चंद्र + सूर्य) mod 360) / 13.333333 ) + 1     → 1..27
करण    = floor( ((चंद्र − सूर्य + 360) mod 360) / 6 ) + 1       → 11 करण तालिका
```

### ⚠️ सबसे बड़ी गलती जो लोग करते हैं
हिंदू दिन **सूर्योदय से सूर्योदय** तक होता है, रात 12 बजे से नहीं। तिथि 19–26 घंटे चलती है।
"आज की तिथि" = **आज सूर्योदय के समय जो तिथि चल रही थी।**
यही एक बात ग़लत हुई तो पूरा ऐप एक दिन आगे-पीछे दिखाएगा।

### लाइब्रेरी
| विकल्प | फ़ैसला |
|---|---|
| Swiss Ephemeris | ❌ AGPL लाइसेंस — बंद-स्रोत ऐप में डालने से पहले लाइसेंस पेज ख़ुद पढ़ो |
| **Meeus एल्गोरिदम ख़ुद Dart में** | ✅ **यही करो** — गणित सार्वजनिक, कोई लाइसेंस नहीं, ~1 कलामात्र सटीकता काफ़ी |
| कोई ऑनलाइन API | ❌ ऑफलाइन होना ही ताक़त है |

### काम की सूची
- [ ] Julian Day + ΔT
- [ ] सूर्य का सायन देशांतर (Meeus)
- [ ] चंद्र का सायन देशांतर (ELP2000 का छोटा रूप — 60 पद काफ़ी)
- [ ] लाहिरी अयनांश → निरयन
- [ ] तिथि, नक्षत्र, योग, करण **+ हर एक का समाप्ति समय**
- [ ] सूर्योदय/सूर्यास्त (अक्षांश, देशांतर, ऊँचाई)
- [ ] मास और पक्ष — **अमांत और पूर्णिमांत दोनों** (सेटिंग में चुनने दो)
- [ ] विक्रम संवत्, शक संवत्, अयन, ऋतु — संकल्प के लिए

**आगे बढ़ने की शर्त:** 30 तारीख़ें छपे हुए ठाकुर प्रसाद पंचांग से मिल जाएँ।

## चरण B — मुहूर्त + व्रत इंजन (अक्टूबर 2026, 3 हफ़्ते)

पूरा तालिका का खेल है, कोई नई खगोल गणना नहीं।

| क्या | कैसे | मुश्किल |
|---|---|---|
| चौघड़िया | दिन के 8 भाग, रात के 8; क्रम वार से | आसान |
| राहुकाल, यमगंड, गुलिक | दिन के 8 भाग, वार से index | आसान |
| अभिजित मुहूर्त | दिन का 8वाँ मुहूर्त | आसान |
| होरा | सूर्योदय से 24 ग्रह-घंटे | आसान |
| पंचक, भद्रा, गंडमूल | नक्षत्र/करण से flag | मध्यम |
| काम के हिसाब से शुभ दिन | मान्य तिथि/नक्षत्र/वार की सूची → 6 महीने के दिनों को अंक दो | मेहनत का |

**v1 में 6 काम:** विवाह · गृह प्रवेश · मुंडन · वाहन ख़रीद · नामकरण · भूमि पूजन

⚠️ हर मुहूर्त के नीचे लिखो: *"ये सामान्य शुभ तिथियाँ हैं, अंतिम निर्णय अपने पंडित जी से करें।"*

### व्रत–त्योहार: तारीख़ें कभी हाथ से मत भरना
हर त्योहार को **नियम** की तरह लिखो, ऐप किसी भी साल की तारीख़ ख़ुद निकालेगा:

```json
{ "id": "ganesh_chaturthi", "name": "गणेश चतुर्थी",
  "मास": "भाद्रपद", "पक्ष": "शुक्ल", "तिथि": 4,
  "नियम": "मध्याह्न_व्यापिनी", "पूजा_id": "ganesh_pujan" }
```

- ~120 त्योहार नियम की तरह (एकादशी, प्रदोष, संकष्टी, पूर्णिमा, अमावस्या अपने आप बनेंगे)
- "व्यापिनी" नियम ज़रूर लगाओ — यही वजह है कि कभी-कभी दो दिन त्योहार दिखता है
- हर त्योहार को उसकी पूजा विधि से जोड़ो

## चरण C — UI + विधि प्लेयर + संकल्प जनरेटर (नवम्बर 2026, 4 हफ़्ते)

### संकल्प जनरेटर — ऐप का सबसे बड़ा हथियार
```
"ॐ विष्णुर्विष्णुर्विष्णुः … {संवत्} … {अयन} … {ऋतु} … {मास} …

```
placeholders सब पंचांग इंजन से। {नाम} {गोत्र} {स्थान} एक बार यूज़र से, फिर हमेशा याद।
**बाज़ार में किसी के पास नहीं है।**

### स्क्रीन्स (12)
| स्क्रीन | मुख्य काम |
|---|---|
| होम — आज | आज का पंचांग सार, "आज क्या करें", आने वाला व्रत, खोज |
| पूजा सूची | श्रेणी अनुसार, बड़े कार्ड, खोज |
| पूजा विवरण | परिचय, समय, कठिनाई, कब करें, "शुरू करें" |
| सामग्री सूची | टिक करने वाली लिस्ट + **WhatsApp पर भेजो** |
| **संकल्प** | नाम/गोत्र/जगह → पूरा संकल्प वाक्य + ऑडियो |
| विधि प्लेयर | कदम-दर-कदम, **बहुत बड़े अक्षर**, ऑडियो, स्क्रीन चालू रहे |
| पंचांग | दिन का पूरा, समाप्ति समय के साथ |
| महीना कैलेंडर | व्रत–त्योहार, टैप → पूजा |
| मुहूर्त | काम चुनो → 6 महीने के शुभ दिन |
| चौघड़िया/राहुकाल | आज का समय-चक्र |
| रिमाइंडर | पुण्यतिथि/व्रत, हर साल अपने आप |
| सेटिंग | भाषा, अमांत/पूर्णिमांत, शहर, विज्ञापन हटाओ |

**डिज़ाइन का नियम:** विधि प्लेयर में अक्षर बहुत बड़े, स्क्रीन बंद न हो (`WakelockPlus`)। आदमी ज़मीन पर बैठा है, हाथ में जल है, फ़ोन दो फ़ुट दूर है।

## चरण D — कंटेंट (अक्टूबर–दिसम्बर, कोडिंग के साथ)

**इस ऐप में कोडिंग 40% है, कंटेंट 60%।**
12 पूजाओं की सूची और स्थिति → `06_CONTENT_TRACKER.md`

### एक पूजा बनाने की प्रक्रिया
| चरण | समय |
|---|---|
| शोध (कम से कम 3 स्रोत मिलाओ) | 2 घंटे |
| ड्राफ़्ट (सामग्री + कदम + मंत्र + सरल अर्थ) | 2 घंटे |
| पंडित जी की जाँच (₹500–1000 दक्षिणा) | 1 घंटा |
| ऑडियो रिकॉर्डिंग (पंडित जी की आवाज़ में) | 1 घंटा |
| जाँच और सुधार | 1 घंटा |
| **कुल** | **~7 घंटे + ~₹800** |

**12 पूजाएँ = ~85 घंटे + ~₹10,000**

### ⚠️ कॉपीराइट
मंत्र, चालीसा, आरती हज़ारों साल पुराने = सार्वजनिक।
**लेकिन** किसी प्रकाशक की छपी टीका या T-Series की रिकॉर्डिंग = कॉपीराइट।
→ **अपनी रिकॉर्डिंग, अपना अर्थ। इंटरनेट से ऑडियो मत उठाना।**

### ऑडियो
- मोनो, ~32 kbps (Opus/AAC) → एक पूजा 8–12 मिनट ≈ 2–3 MB
- 12 पूजाएँ ≈ 30 MB → सीधे बंडल
- 20+ पूजाओं पर → Play Asset Delivery (Google मुफ़्त होस्ट करता है)
