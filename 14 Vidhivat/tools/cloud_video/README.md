# Cloud app recording — free GitHub Actions emulator\n\nयह व्यवस्था Vidhivat को किसी local PC, Firebase account, billing plan या Android emulator के बिना चलाती है:\n\n```\nGitHub Actions → debug APK build → cloud Android emulator में APK install\n               → emulator screen recording → GitHub Actions artifact\n```\n\nWorkflow: `.github/workflows/vidhivat-cloud-video.yml`\n\n## कोई setup या secret नहीं\n\nWorkflow GitHub के cloud runner पर चलता है। Firebase, Google Cloud billing, service-account key और APK upload किसी third-party testing platform पर नहीं होता। यह repository source से APK बनाता है, temporary emulator पर install करता है, और run समाप्त होते ही emulator मिट जाता है।\n\n## चलाना\n\n1. GitHub repository का **Actions** tab खोलें।\n2. **Vidhivat cloud app video** workflow चुनें।\n3. **Run workflow** दबाएँ।\n4. Default `50` seconds रहने दें, या 10–180 seconds का duration भरें।\n5. Run पूरा होने पर **Artifacts** में `vidhivat-emulator-recording-<run-id>` डाउनलोड करें। इसमें:\n   - `vidhivat-emulator.mp4` — साफ app screen recording\n   - `first-frame.png` — recording शुरू होने का screenshot\n\n## अगला सुधार\n\nपहला run सिर्फ़ app का clean opening recording बनाता है। उस screenshot/video से हम exact tap sequence तय करेंगे—फिर workflow में fixed UI steps जोड़कर हर बार वही puja journey रिकॉर्ड होगी। उसके बाद original voice और approved B-roll को final video में जोड़ा जा सकता है।\n\n## ध्यान रखें\n\n- यह Play Store APK नहीं निकालता और किसी आपके real phone पर install नहीं करता।\n- Public repository में GitHub-hosted runner आम तौर पर free रहता है; private repository में आपके GitHub plan के included Actions minutes लागू हो सकते हैं।\n- Secret, keystore, APK और final long videos git में commit न करें।\n
