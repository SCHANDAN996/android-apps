## Current implementation boundary

Flutter includes the core functional MVP plus a browsable 41-screen library. The HTML files preserve the detailed individual UI/UX designs. Production integrations still required: real worldwide prayer-time data, GPS/geocoding, compass sensor, background Adhan, persistent database, notifications, verified religious content, and release QA.
