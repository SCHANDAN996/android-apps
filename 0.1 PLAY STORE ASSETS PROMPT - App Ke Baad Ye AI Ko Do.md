# 0.1 — Play Store Assets Master Prompt (Pro-Level) 🚀

यह एक **Professional ASO (App Store Optimization) & Copywriting Master Prompt** है। इसे कॉपी करके किसी भी AI (जैसे: ChatGPT, Claude, Gemini) को दें ताकि वह आपके नए बने ऐप के लिए पब्लिश-रेडी, हाई-कन्वर्टिंग प्ले स्टोर लिस्टिंग और ग्राफिक्स प्लानिंग तैयार कर सके।

---

```markdown
Role: You are a World-Class App Store Optimization (ASO) Expert, Elite Android Growth Marketer, and Professional App Copywriter. Your mission is to generate a comprehensive, policy-compliant, and high-converting launch kit for my newly built Android app.

You will use advanced copywriting frameworks (such as PAS - Problem-Agitate-Solve and AIDA - Attention-Interest-Desire-Action) to write descriptions that maximize downloads (Visitor-to-Install Conversion Rate).

---
### 🛠️ INPUT APP METADATA & PROFILE
(Please read these inputs first to understand the context of the app):

- **App Name / Brand Name:** [e.g., "Kisan Calculator - खेती का हिसाब"]
- **Core Purpose & Utilities:** [e.g., "Bigha conversion, Crop profit calculation, Interest/Sood calculation, tractor/labor cost tracking"]
- **Target Audience:** [e.g., "Farmers, village merchants, tractor drivers, rural citizens in India"]
- **Primary Keywords (High Traffic):** [e.g., "Kisan Calculator", "खेती कैलकुलेटर", "खेत नापने वाला ऐप"]
- **Secondary Keywords (ASO Indexing):** [e.g., "जमीन कनवर्टर", "ब्याज कैलकुलेटर", "bigha to acre", "fasal munafa"]
- **Primary Language:** [e.g., "Hindi (Devanagari) + English" or "English Only"]
- **Developer Name:** [CHANDAN SINGH]
- **Support & Legal Email:** [all.chandansingh@gmail.com]
---

### 📦 ASSETS TO GENERATE (FOLDER STRUCTURE: `play_store_assets/`)

Go through the following steps to output the files one-by-one:

#### FILE 1: `store_listing.md` (Optimized Metadata)
Write the customer-facing texts for the Play Store listing:
1. **App Title (Strictly Max 30 Characters):** Provide 3 options. The primary keyword must be at the beginning of the title (high algorithm weight).
2. **Short Description (Strictly Max 80 Characters):** Provide 3 high-converting options. Focus on the core pain point (PAS framework) and use strong action verbs (e.g., "बचायें", "नापें", "हिसाब करें").
3. **Full Description (Max 4000 Characters):** Use the **AIDA framework**. Do NOT stuff keywords; integrate them naturally at 1.5% density.
   - **Hook:** localized attention grabber (e.g., "क्या आपको भी खेत की नाप या ब्याज के हिसाब में समस्या होती है?").
   - **Pain Point:** Agitate the risk of manual calculation errors.
   - **Features & Benefits:** List 4-5 major features using bullet points and clean emojis. For each feature, write a 2-line explanation focusing on *user benefit*.
   - **Offline & Security Promise:** Explicitly mention: "100% offline, data stays securely on your phone."
   - **Call To Action (CTA):** A strong closing urging them to download.

#### FILE 2: `keywords_aso.md` (Search Engine Indexing)
- 15 search keywords categorized by Search Volume (High, Medium, Low).
- Recommended Play Store Category (e.g., Finance, Tools).
- 5 Recommended Play Store tags.

#### FILE 3: `screenshots_plan.md` (Visual Conversion Storyboard)
Plan for **6 vertical screenshots** (Aspect ratio 9:16 or 9:20):
- **Screenshot Name & UI Source:** (e.g., "Screenshot 1: Home & Dashboard")
- **Visual Description:** UI mockups, fields pre-filled with realistic data (e.g., local land values, crop names) for context.
- **Top Caption Text (Strictly Max 5 Words):** Bold headline (e.g., "सटीक खेत नाप!")
- **Bottom Sub-caption (Strictly Max 8 Words):** Quick value prop (e.g., "बीघा, एकड़ और हेक्टेयर में तुरंत बदलें")

#### FILE 4: `graphics_specs.md` (App Icon & Banner Concept)
- **App Icon (512x512):** Design concept — colors (Hex codes), central symbol/logo, style (modern flat, bold shadows).
- **Feature Graphic (1024x500):** Visual layout description, headline text to render, phone mockup placement.

#### FILE 5: `privacy_policy.html` (Legal Compliance)
Generate a clean, copy-pasteable HTML document ready to host on Blogger or GitHub Pages:
- Disclose AdMob/Google Play Services SDK usages.
- Explicitly declare no collection of personal data.
- Detail reason for requested permissions (e.g., Storage, Microphone).
- Insert Developer Name: CHANDAN SINGH and Contact: all.chandansingh@gmail.com.

#### FILE 6: `data_safety_answers.md` (Play Console Questionnaire)
- Exact answers (Yes/No selections) for the Play Console Data Safety questionnaire based on an offline-first app structure.

#### FILE 7: `release_notes.txt` (App Store Updates - Max 500 Chars)
- Version 1.0 release notes in both Hindi (Devanagari) and English.

---

### 🎨 OUTPUT FORMAT RULES:
1. Provide the output in a clean, copy-pasteable Markdown format.
2. Ensure the copy is localized beautifully (e.g., use terms like 'हिसाब', 'बीघा', 'ब्याज' for Hindi belt).
3. Do not leave any placeholders empty except the developer name and email provided.
```
