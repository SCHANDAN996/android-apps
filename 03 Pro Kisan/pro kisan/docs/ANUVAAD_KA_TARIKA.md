## 2. यह कैसे काम करता है

`lib/data/palan/palan_i18n.dart` में एक map है:

```dart
final Map<String, Map<String, String>> kPalanI18n = { ... };
//         ↑ हिंदी वाक्य        ↑ भाषा-कोड → उस भाषा का वाक्य
```

**चाबी हिंदी का वाक्य ही है** (कोई id नहीं)। `tx()` पहले इस map में देखता
है; न मिले तो पुराना बर्ताव — देवनागरी वालों (hi/mr/bho) को हिंदी, बाक़ी को
अंग्रेज़ी।

इसीलिए **अधूरा छोड़ना सुरक्षित है** — जो नहीं जुड़ा वह अंग्रेज़ी में दिखेगा,
कुछ टूटेगा नहीं।

## 4. कहाँ लिखना है

`lib/data/palan/` में `palan_i18n_deep_25.dart` से आगे नई फ़ाइल बनाइए
(1 से 24 तक भर चुकी हैं)। **हर फ़ाइल में 25-30 वाक्य** रखिए — बड़ी फ़ाइल
सँभालना कठिन हो जाता है।

### फ़ाइल का ढाँचा — बिल्कुल ऐसा ही

```dart
/// गहरा अनुवाद — भाग 25: <यहाँ लिखिए किस तरह के वाक्य हैं>
///
/// ⚠️ **यह मशीन का किया अनुवाद है** — देखें `palan_i18n.dart` की चेतावनी।
library;

const Map<String, Map<String, String>> kPalanI18nDeep25 = {
  'यहाँ हिंदी वाक्य हूबहू': {
    'ta': '…', 'te': '…', 'kn': '…', 'bn': '…',
    'gu': '…', 'pa': '…', 'mr': '…', 'bho': '…',
  },
  // …
};
```

> ⚠️ **चाबी हूबहू वही हो जो data फ़ाइल में है।** Dart में लगे हुए string
> अपने आप जुड़ जाते हैं —
>
> ```dart
> hi: 'पहला हिस्सा '
>     'दूसरा हिस्सा।',
> ```
>
> चलते समय यह **एक ही** वाक्य बनता है, इसलिए चाबी में भी पूरा जुड़ा हुआ
> वाक्य लिखिए। सिर्फ़ पहला टुकड़ा लिखेंगे तो अनुवाद कभी लगेगा ही नहीं।

### फिर उसे जोड़िए — `palan_i18n.dart` में दो जगह

```dart
import 'palan_i18n_deep_25.dart';   // (1) ऊपर import की सूची में

final Map<String, Map<String, String>> kPalanI18n = {
  ...kPalanI18nDeep24,
  ...kPalanI18nDeep25,              // (2) यहाँ, kPalanI18nCore से पहले
  ...kPalanI18nCore,                //     ⚠️ Core हमेशा सबसे आख़िर में रहे
};
```

> `kPalanI18nCore` हाथ से जाँची हुई परत है। वह **सबसे आख़िर** में फैलती है
> ताकि टकराव में वही जीते। इसका क्रम मत बदलिए।

## 5. ⚠️ अनुवाद के नियम — इन्हें तोड़ा तो किसान का नुक़सान होगा
