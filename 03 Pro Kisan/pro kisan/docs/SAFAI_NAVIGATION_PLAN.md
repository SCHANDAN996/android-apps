# 🧭 भाग 2 — रास्ता (navigation)

## पहले क्या ख़राब था

आपने ठीक पकड़ा — घेरा इतना बड़ा बनता था कि चौथाई screen घिर जाती और पता
ही नहीं चलता कि छूना कहाँ है।

**असली वजह:** हर screen `tutorial_coach_mark` को **बिना कुछ तय किए**
बुलाती थी। उस package का —

- default आकार **गोला** है → छोटे बटन के लिए भी बड़ा गोला
- default `paddingFocus` बड़ा है → और फैल जाता
- आगे बढ़ने का **कोई बटन नहीं** → कहीं भी छूने से अगला क़दम

## अब — `lib/ui/widgets/pro_tour.dart`

एक ही जगह सब तय है, सारी screen वही इस्तेमाल करती हैं:

| | पहले | अब |
|---|---|---|
| आकार | गोला (चौथाई screen) | **चौकोर**, जितना बड़ा असली बटन है |
| घेरा | बहुत बड़ा | बस 4 pixel |
| आगे बढ़ना | कहीं भी छुओ | **पूरी चौड़ाई का "आगे →" बटन**, 48 ऊँचा |
| कितना बचा | पता नहीं | **"2 / 5"** ऊपर लिखा |
| डिब्बे की जगह | तय (कभी screen से बाहर) | ऊपर/नीचे — जहाँ जगह हो |
| असली बटन दबे तो | आगे बढ़ जाता | **कुछ नहीं** (ग़लती से एंट्री न हो) |

## 🆕 पहली बार आने वाले किसान के लिए — नीचे के 5 tab

यह सबसे बड़ी कमी थी। किसान पहली बार ऐप खोलता और उसे पता ही नहीं चलता कि
दूध कहाँ लिखें, पशु कहाँ जोड़ें, मंडी भाव कहाँ है।

अब पाँच क़दम में पूरा ऐप समझ आता है:

| क़दम | tab | क्या लिखा है |
|---|---|---|
| 1/5 | 🏠 घर | *"आपका आज का हिसाब — कितना दूध, कितना पैसा, और मौसम।"* |
| 2/5 | 🥛 दूध | *"रोज़ की सुबह-शाम की एंट्री यहाँ लिखिए।"* |
| 3/5 | 🐄 पशु | *"ब्याने और टीके की तारीख़ ऐप ख़ुद याद दिला देगा।"* |
| 4/5 | 🌾 खेती | *"खाद-बीज, खेत की माप, और आज का मंडी भाव।"* |
| 5/5 | ☰ और | *"सरकारी योजना, मौसम, समाचार और सेटिंग।"* |

**किसान की चुनी हुई भाषा में ही दिखता है** — हिंदी/अंग्रेज़ी अभी तैयार हैं,
बाक़ी 8 का अनुवाद `docs/UI_ANUVAAD_TASK.md` से करवाना है।

अनुमति वाले dialog और Drive वाले सवाल के **बाद** चलता है, ताकि दो चीज़ें
एक साथ न दिखें।
